## メモ
- `StringBuilder`
  - **概要**: 可変（`mutable`）な文字列を扱う Java 標準クラス。
  - **初期容量 (Capacity)**:
    - デフォルト: `16`
    - 文字列指定 (`new StringBuilder("abc")`): `3 + 16 = 19`
    - 数値指定 (`new StringBuilder(100)`): 指定した数値分のバッファをあらかじめ確保
  - **メリット**:
    - **高速 & 省メモリ**: 同一配列を直接書き換えるため、`String` のような一時オブジェクトが作られず **GC (ゴミ拾い) の負担を最小化**できる。
    - **操作が豊富**: `.reverse()`, `.deleteCharAt()`, `.insert()` など、スタックやキューのように使える便利な API が揃っている。
  - **デメリット / 注意点**:
    - **スレッド非安全**: マルチスレッド環境で共有するとデータ破壊の恐れがある（※その場合は `StringBuffer` を使う）。
    - **配列拡張のコスト**: 追加文字数が分かっているのにデフォルト（16）のまま使うと、何度も配列の再確保（`System.arraycopy`）が起きて速度低下する。
